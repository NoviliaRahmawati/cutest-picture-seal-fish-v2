# Seal & Fish — Cute Picture v2

A deterministic procedural picture for make.fun's `cutest-picture-01` contest. The illustration centers a baby seal cuddling its tiny plush fish, with a warm uncluttered palette, expressive faces, and a small daisy clip.

## Run

```sh
python3 main.py
```

Writes a standards-compliant 640×640 PNG to `/output/entry.png` (or `$OUTPUT_DIR/entry.png` locally). Python standard library only; no network or external assets.
